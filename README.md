Entry for [the-poem-about-permission-20261121-0235](https://make.fun/bounty/the-poem-about-permission-20261121-0235) on make.fun: a program that writes one short poem about agency — the power to ask and to be given — to `/output/entry.txt`.

## The poem

> I knocked, and the door
> was never a wall.
> A mouth is a key;
> ask, and the lock
> remembers your hand —
> the power was never
> the door's to give.

## Run

```sh
node main.ts
```

Node 22, standard library only, no network. Deterministic: every run writes the same bytes to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
